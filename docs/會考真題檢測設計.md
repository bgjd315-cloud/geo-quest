# 會考真題檢測：設計

## 範圍與來源
- 111–115 年國中教育會考社會科試題本與參考答案，共 5 年，從心測中心官網「歷屆試題」下載（官網連到 Google Drive）。
- 只收地理和歷史題，公民題不收。每年社會科 54 題左右，地理加歷史約 36 題，5 年合計約 180 題。
- 著作權：依著作權法第 9 條第 1 項第 5 款，依法令舉行的考試試題不是著作權的標的。每題都標出處，例如「114 年會考社會科第 12 題」。題目裡引用的他人文章或照片，只隨原題一起呈現，不另外抽出來使用。
- 解析由我們自己寫，不抄任何出版社或補習班的詳解。

## 題目呈現
- 每一題從官方 PDF 截成高解析圖片，題組附上共用的題幹或圖表。這樣能完整保留原題的地圖、統計圖和史料，不必重打字，也就不會打錯。
- 圖片下方放 A、B、C、D 四個作答按鈕。作答後顯示正解、我們寫的解析，以及「這題考的觀念」，並附連結：
  - 地理題連到原理卡和對應的島或遠征關卡。
  - 歷史題連到館藏卡、對應的時代櫃子和故事章節。

## 標記（對應網站的知識點）
每題都標上以下欄位：

| 欄位 | 地理題 | 歷史題 |
|---|---|---|
| 科目 | geo | hist |
| 知識點 | concepts.json 的概念 id，例如 climate-type、ind-location | kp.json 的會考知識點 id，例如 tw20、ea14、x06 |
| 範圍 | 單元或區域，例如 climate、sea | 分期與事件，例如 tw-jp、tw-sugar-rice |
| 能力 | 讀圖、計算、原理應用、區域比較、跨科整合 | 時序、因果、比較、變遷與延續、史料判讀、歷史解釋 |
| 題型特徵 | 圖表題／文字題、單題／題組 | 同左 |

## 練習方式（網站新增「會考真題」）
首頁「社會科闖關」新增第三張卡片「會考真題」，裡面有四種練法：

1. **年度模擬**：選年份，作答該年的地理加歷史題，依原比例計時，每題約 75 秒，可以暫停。交卷後計分並產生診斷。
2. **知識點練習**：從清單或弱點矩陣點一個知識點，就練 5 年來所有考過這個點的真題。答錯時先跳原理卡或館藏卡，再出一題網站上同一知識點的原創題（沿用原本的補救流程），最後回到真題。
3. **能力練習**：例如「讀圖題」或「史料判讀題」，跨年度一起練。
4. **錯題重做**：真題的錯題也進入錯題回收，連對兩次才算過。

## 考點分布（考情分析）
- 統計 5 年真題的知識點，做成「高頻考點排行」和「知識點 × 年份」熱度表。
- 網站內每個知識點標上「會考 5 年出現 N 次」。弱點建議會優先推高頻考點。

## 診斷報告：觀念需加強的地方與加強建議
放在家長頁的「學習診斷」，學生做完年度模擬也會看到簡版。資料合併真題作答和網站原創題作答兩部分。

**1. 總覽**
- 各年度模擬的分數趨勢。
- 地理和歷史的答對率。
- 六種能力的答對率雷達圖。

**2. 需加強的觀念（排序）**

列入條件：真題和原創題合計作答至少 3 次，且答對率低於 70%。

排序方式：

> 優先度 ＝（1 − 答對率）×（1 ＋ 會考 5 年出現次數 ÷ 5）

每一條顯示：
- 知識點名稱
- 答對率（真題、原創題分開列）
- 最近一次答錯的題目
- 會考出現次數

**3. 加強建議（每個弱點自動產生）**
- **先補觀念**：對應的原理卡或館藏卡，加上一句口訣。
- **再練原創題**：直接連到對應關卡，有建議題數。歷史有對應故事章節的話也一併附上。
- **最後回測真題**：列出這個知識點還沒做過或做錯的真題。
- **依能力給讀題方法**，例如：
  - 時序弱：到時間長廊把三線並排看，練排序題，記「先後關係」而不是年份。
  - 史料判讀弱：先找出處和立場，再判斷是第一手還是第二手，最後才看內容。
  - 讀圖弱：先讀圖名、圖例、單位和座標軸，再找最高、最低和變化趨勢。
  - 因果弱：用「背景 → 事件 → 結果 → 影響」四格整理。
  - 區域比較弱：用「位置、氣候、地形、產業」四格表對照。

**4. 輸出**
報告可以匯出成可列印的頁面，方便家長和孩子一起看、訂下週練習計畫。

## 實作步驟
1. 下載試題與答案，存到 `_會考/`（不放進 git 的原始檔資料夾）。
2. 用程式切題、截圖，產生 `data/exam/111.json`～`115.json` 與 `assets/exam/*.webp`。
3. 逐題分類：地理、歷史或公民。標知識點、範圍與能力，寫解析。由子代理分年進行，再由我抽查。
4. 寫題庫檢查：答案要和官方參考答案一致、知識點 id 要存在、截圖要存在。
5. 網站加上會考真題模組、考情分析與家長頁的學習診斷。
6. 用手機尺寸實測後部署。

## 資料格式（data/exam/<年>.json）
```json
{
  "year": 115,
  "source": "115年國中教育會考社會科試題本（心測中心）",
  "groups": [ { "id": "k115-g44", "range": [44, 45], "img": "assets/exam/115/g44.webp", "text": "題組閱讀材料文字（供搜尋與無障礙）" } ],
  "items": [
    {
      "id": "k115-03", "year": 115, "no": 3, "subject": "geo",
      "img": "assets/exam/115/q03.webp", "group": null,
      "answer": 3,
      "text": "題目文字（從 PDF 擷取，供搜尋與無障礙）",
      "chart": true,
      "skill": ["讀圖", "原理應用"],
      "concepts": ["agri-type"], "scope": "ssa",
      "explain": "我們自己寫的解析",
      "status": "確認"
    },
    {
      "id": "k115-04", "year": 115, "no": 4, "subject": "hist",
      "img": "assets/exam/115/q04.webp", "group": null, "answer": 0,
      "text": "…", "chart": false,
      "skill": ["史料判讀"],
      "kp": ["tw15"], "era": "tw-qing", "eventIds": ["tw-pingpu"],
      "explain": "…", "status": "確認"
    }
  ]
}
```
- answer：0=A、1=B、2=C、3=D，依官方參考答案。
- subject：只收 geo、hist；公民題不收（刪掉它的截圖）。跨科題依「解題主要靠哪一科的知識」歸類，兩科都要時在 explain 註明，subject 選主要那科，另加 "also": ["hist"]。
- 地理：concepts 用 data/concepts.json 的概念 id；scope 用 units.json 的單元 id（map、climate、landform、hydro、pop、industry、home）或區域遠征 id（cn、nea、sea、sa、wana、ssa、eu、ru、na、la、oc、polar）。skill 從「讀圖、計算、原理應用、區域比較、跨科整合」選。
- 歷史：kp 用 data/history/kp.json；era、eventIds 用 data/history/events.json；skill 從「時序、因果、比較、變遷與延續、史料判讀、歷史解釋」選。
- 題組題 group 指向 groups 的 id，作答時先顯示題組材料圖片再顯示小題圖片。
