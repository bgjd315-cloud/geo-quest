# 會考真題公民題標記指引（給子代理）

先讀：D:\geo-quest\docs\會考真題檢測設計.md（資料格式）、D:\geo-quest\docs\會考真題標記指引.md（流程相同）、D:\geo-quest\公民_C0_確認清單.md（第二節單元與概念、第九節家長決定：一律依課本）、D:\geo-quest\data\civics\concepts.json、pairs.json。

## 和史地不同的地方
- 這次只處理**公民題**（地理、歷史題已經做好在 data/exam/<年>.json，不要動那些檔）。
- 每題截圖在 D:\geo-quest\_會考\crops\<年>\q??.webp、題組材料 g??.webp；題目文字在 _會考\index_<年>.json；官方答案圖 _會考\ans_<年>_p1.png／p2.png（只看「社會」欄）。
- 哪些題是公民：data/exam/<年>.json 已收的題號以外的，就是公民題（跨科題已歸地理或歷史的不要重收）。
- 寫成**新檔** data/exam/<年>c.json：{"year":<年>,"source":"<年>年國中教育會考社會科試題本（心測中心）","groups":[…],"items":[…]}。
  - id：k<年>-NN（和史地同一套編號，不會重複，因為題號不同）；題組 id 若和史地檔已有的相同（同一題組含公民小題），**沿用同一個 id 但寫進本檔的 groups**（網站會合併；不要改史地檔）。
  - subject："civ"；img："assets/exam/<年>/qNN.webp"（圖片會由 scripts/exam-sync.py 從 crops 複製過去，你不用複製）。
  - 標記：domain（社會／政治／法律／經濟／全球關聯）、book（1–6）、unit（如 c4-2）、concepts（data/civics/concepts.json 的 id）、skill（概念辨析、規範判斷、經濟推理、圖表判讀、觀點評估，選 1–2 個）、confusablePair（選填，pairs.json 的 id）、chart、answer（0=A…3=D，依官方答案）、text、explain（自己寫，依課本說法；**不另外比較現行法**）、status "確認"。
- 自己解每一題並和官方答案核對，不一致要在回報列出（以官方為準）。
- 對不到任何概念的題目，在回報列出（不要硬標），之後會補概念。
- 檢查：JSON 可解析、id 都存在、answer 0–3、crops 裡的圖存在。

## 回報
每年公民題數、和官方答案不一致處、對不到概念的題目、最常出現的概念。
