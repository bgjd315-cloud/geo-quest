# 公民出題與故事寫作指引（給子代理）

網站是 D:\geo-quest 社會科闖關的公民模組《青禾里》，給準備會考的國三學生自學。全部用繁體中文、臺灣用語。

## 先讀
- `D:\geo-quest\docs\公民模組需求.md`：家長的完整需求。注意 §三 角色、§五 格式、§七 故事結構、§八 題型、§十 依據與界線。
- `D:\geo-quest\公民_C0_確認清單.md`：第二節是單元與概念，第三節是混淆對，第四節是角色，第五節是各章大綱（章名、角色、迷思句說話者），**第九節是家長決定**。
- `D:\geo-quest\data\civics\concepts.json`、`pairs.json`、`characters.json`：所有 id 都要用這三個檔裡的。
- **範本**（照它們的格式與水準寫）：`data\civics\stories\law\c4-2.json`、`data\civics\stories\politics\c3-6.json`，以及可讀版 `D:\geo-quest\公民_C1_試寫兩章.md`。
- 題目欄位格式另外參考 `data\history\questions\tw-1a.json`，以及 `scripts\validate.js` 的 checkBody。

## 最高原則（家長決定）
- **一律依照課本**，以免混淆孩子。課本在 `D:\geo-quest\_課本\civics\_text\`。
- 課本和現行法律不一致時，題目照課本，解析也不提現行法的差異。例如：酒駕罰鍰、最低工資用課本的 115 年數字、曝險少年「原則上先交少年輔導委員會」、公平會職掌包含囤積。
- 不畫供需曲線，不用「需求變動／需求量變動」這類名詞；只考課本寫的「價格與購買、生產數量的關係」和「非價格因素」。
- 課本沒教的內容不寫。統計數據依課本使用，出處寫「康軒國中公民○冊第○課」。
- 選舉、政黨、候選人一律虛構，不碰時事。觀點評估題要呈現雙方論點，只評「依據是否成立」。
- 家暴、少年事件、詐騙等題材，敘事要克制，重點放在程序、保護措施與求助管道。
- 經濟情境的數字可以虛構，但要標「情境數值」。計算題附 `formula` 欄位，讓程式能驗算。
- 所有內容 `status` 一律寫 `"確認"`：家長決定直接上線。

## 每個單元要交的東西
1. **故事一章**：`data\civics\stories\<domain>\<unit>.json`，一個檔放一章，格式同範本。
   - domain 對照：社會 society、政治 politics、法律 law、經濟 economy、全球關聯 global。
   - 章名、角色、迷思句說話者照 C0 第五節大綱。
   - 開場 300–400 字、判斷點加解析、嵌入題 2–4 題、迷思糾錯、制度對照（legalRefs）、fictionNotes；法律單元另加完整 caseCard。
2. **概念闖關題**：寫進 `data\civics\questions\b<冊>.json`，格式為 `{"book":N,"questions":[...]}`。
   - 題數：第一至五冊每單元 8–10 題，第六冊每單元 6–8 題。
   - id 寫成 `cq-<unit>-NN`，例如 `cq-c4-2-01`。
   - 每題都要有 domain、book、unit、concepts、skill；level 填 unit id；法律題要有 legalRefs，例如「民法第12條」。
   - 有混淆的題目要標 confusablePair，選項可以加 `optionConcepts`（每個選項對應的概念 id），讓網站能記錄混淆。
   - 題型要混合：情境判斷、流程排序、並排辨析、價格與數量判斷（經濟）、計算題、迷思糾錯、觀點評估。
   - 每組混淆對至少要有一題「並排辨析」：同一情境只改一個條件，答案從 A 變成 B。
   - 單選約佔 45%。選項長度要平均，正解不可以總是最長的那個。每題都要有解析。
3. **概念卡**：寫進 `data\civics\cards\b<冊>.json`，格式為 `{"book":N,"cards":{"<概念id>":{"title","text","tip"}}}`。負責單元的每個概念都要一張；text 寫定義、判斷要點、常見誤解，2–4 行。

## 特殊檔案（只有指定的子代理寫）
- `questions\cases.json`：案件分流挑戰，由法律子代理寫。至少 30 個短案件，每個都要有：情境、事件類型（民事、刑事、行政）、主管機關、救濟途徑選項、正解、解析、legalRefs。
- `questions\boss-b<冊>.json`：每個子代理寫自己那一冊的跨冊魔王題組 2–3 組，格式 `{"book":N,"questions":[...]}`；每組是一題題組題（parts），id 用 `cb-b<冊>-NN`，level 用 `boss-<domain>`，情境要串到前面冊次學過的概念。各冊一檔，不會互相覆蓋。
- 已經有範本的兩章（`stories\law\c4-2.json`、`stories\politics\c3-6.json`）不要重寫；這兩個單元只補闖關題和概念卡。

## 檢查與回報
- 只覆寫自己負責的檔案。`cards\b<冊>.json` 和 `questions\b<冊>.json` 都是一冊一檔。
- 寫完執行 `node scripts/validate.js`，修好自己檔案的錯誤。
- 回報：
  - 各單元的故事字數與題數；
  - 混淆對覆蓋情形；
  - 依課本處理、但和現行法不同的地方（只列在回報裡，不寫進題目）；
  - 不確定的地方。

## 補充（範本的欄位）
範本另有 coreConcepts、optionPairs（選項對應的混淆對）、comparison（制度對照，含 ageTable 等並排表）、嵌入題以 lead／question／after 包裝、迷思糾錯有 lead／after。請照範本使用這些欄位。不要改 concepts.json／pairs.json／characters.json；缺的概念列在回報裡。
