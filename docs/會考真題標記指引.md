# 會考真題標記指引（給處理單一年度的子代理）

先讀 D:\geo-quest\docs\會考真題檢測設計.md，「資料格式」那節以它為準；再大致看過 D:\geo-quest\CLAUDE.md。

## 輸入（<年> 換成你負責的年度）
- 題目截圖：D:\geo-quest\assets\exam\<年>\q01.webp～q54.webp，題組材料是 g??.webp。題目有地圖、圖表、表格時，一律用 Read 工具打開圖片來看。
- 擷取文字：D:\geo-quest\_會考\index_<年>.json，裡面有 items[].no、text，以及 groups[].range、text。
- 官方參考答案圖：D:\geo-quest\_會考\ans_<年>_p1.png 是第 1–30 題，ans_<年>_p2.png 是第 31–54 題。只看「社會」那一欄。
- 網站分類：
  - 地理：D:\geo-quest\data\concepts.json、data\units.json。
  - 歷史：data\history\kp.json、data\history\events.json。

## 工作
1. **讀答案並自己解題核對**：從答案圖讀出社會科 54 題的答案。要保留的每一題都自己解一次。解出來和答案不同時，再仔細看一次答案圖。最後以官方答案為準，但每一處不一致都要寫進回報。
2. **分類**：把每題分成地理、歷史或公民。
   - 公民題整題不收，並刪掉它的 q??.webp。
   - 題組圖只有在所屬小題全部是公民時才刪。
   - 跨科題照設計文件的規則處理。
3. **寫資料檔**：完全照設計文件的格式寫 D:\geo-quest\data\exam\<年>.json。
   - id 寫成 k<年>-NN，題組寫成 k<年>-gNN。
   - 只放地理和歷史題；被保留小題用到的題組也要放進 groups。
   - 地理題標 concepts 和 scope，歷史題標 kp、era、eventIds，兩科都要標 skill。
   - 需要看圖、表或地圖才能作答的，chart 設為 true。
   - status 一律填「確認」。
   - text 用 index 裡的題幹加選項，把斷行整理好。
4. **寫解析**：每題 explain 用繁體中文，寫出：
   - 為什麼正解是對的；
   - 主要的錯誤選項錯在哪裡；
   - 這題背後的觀念。
   
   全部用自己的話寫，不抄任何出版社或補習班的詳解。
5. **檢查**：寫一段 node 小程式確認：
   - JSON 能正常解析；
   - 所有 concept、scope、kp、era、event 的 id 都存在；
   - answer 在 0–3 之間；
   - img 指到的檔案存在。

## 回報
- 地理、歷史各幾題，刪掉幾題公民題；
- 和官方答案不一致的題目；
- 不確定該怎麼標的題目；
- 出現最多次的概念或知識點。
