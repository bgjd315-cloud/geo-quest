# 歷史故事寫作指引（時光檔案館・三條故事線）

> 使用者原本需求裡的「七、故事寫作規範／語氣」被截斷了。下面的規範是依需求前段（開場 300–500 字、時代選擇點、嵌入題、時代錯置偵探、虛構與史實對照、解鎖時空卡）和地理故事的做法訂的。使用者補傳原文後，以原文為準修訂。

## 框架
- 讀者是準備會考的國三學生（約 15 歲），用繁體中文、臺灣用語。
- 每章開頭，石虎「阿斑」在《時光檔案館》裡叼來一份被時間蛀蟲咬亂的檔案，例如家書、契約、報紙、日記或物品標籤。玩家（見習檔案員）讀完檔案，把它歸回正確的年代。故事主體是那份檔案裡的世界。
- 三條線：
  - **家族線（臺灣館）**：林家五代人的家書箱，F1～F10。每一章是林家不同世代的一位成員，前後章要有血緣或物品的延續，例如同一只木箱、一枚印章、一句家訓。
  - **物品線（東亞館）**：每章跟著一件物品旅行，T1～T8 加上 T7b。物品可以每章不同（考卷、絲綢、歲幣、瓷碗、茶箱、報紙、行李、家書、訂單），但都由同一個「東亞館藏品櫃」串起來。
  - **調查員線（世界館）**：時空調查局的老調查員「葛老師」（虛構）帶玩家辦案，I1～I10。每章是一個「案件」，由一份可疑的文件或物品開頭。
- 每章大約讀 10 分鐘。

## 語氣與規範
1. 主角、家族、調查員都是**虛構人物**。真實人物（如鄭成功、馬偕、林獻堂、孫中山、拿破崙、安妮）只能當背景出場或被提到，不替他們編造對白、心聲或課本沒有的事蹟。
2. 事件、年代、制度都要符合康軒課本。課本文字在 `D:\geo-quest\_課本\history\_text\`，事件清單在 `data\history\events.json`。
3. 語氣溫暖、好奇、有畫面感，不說教、不煽情。戰爭、屠殺、白色恐怖等沉重事件，照課本的說法平實交代，不渲染暴力細節，也不加入課本以外的政治評價；要讓學生理解當時的人為什麼這樣選擇、承受了什麼。
4. 不寫任何真實的私人資訊。虛構人物的姓名要避免和知名人物同名。
5. 每章結尾要讓學生帶走一個「歷史思考」：因果、比較、變遷或史料觀點，對應這章標的能力。

## 每章的結構（JSON 欄位）
```json
{
  "id": "F1",
  "title": "大員港的通譯",
  "volume": "1上",
  "era": "tw-sea",
  "eventIds": ["tw-dutch", "tw-madou", "tw-guo"],
  "themes": ["對外交流與衝突", "經濟與貿易"],
  "skills": ["史料判讀", "因果"],
  "status": "待審",
  "doc": "阿斑叼來的檔案是什麼（一句話，例如：一封邊角被咬破、寫給「阿兄」的家書）",
  "opening": "開場情境，300–500 字",
  "eraChoice": {
    "prompt": "這份檔案應該放進哪一個時代的櫃子？",
    "options": [
      { "text": "大航海時代（荷、西、鄭氏）", "era": "tw-sea", "correct": true, "feedback": "為什麼對：引用開場裡的線索" },
      { "text": "清帝國時期", "era": "tw-qing", "correct": false, "feedback": "為什麼不對" }
    ]
  },
  "scenes": [
    {
      "text": "故事段落，200–400 字",
      "question": { "...": "嵌入題，格式同題庫題目" }
    }
  ],
  "detective": {
    "intro": "阿斑嗅到這段文字裡混進了不屬於這個時代的東西，把它們找出來！",
    "sentences": ["第 1 句", "第 2 句", "..."],
    "wrong": [2, 5],
    "explain": { "2": "為什麼這句是時代錯置", "5": "..." }
  },
  "factFiction": [
    { "text": "故事裡的某個元素", "fact": true, "note": "課本怎麼說" },
    { "text": "林家阿兄當通譯", "fact": false, "note": "人物是虛構的，但當時確實有……（課本依據）" }
  ],
  "ending": "結尾，100–250 字，帶出這章的歷史思考",
  "unlock": ["tw-dutch", "tw-madou", "tw-guo"]
}
```

## 欄位規則
- **scenes**：每章 3–4 段，每段都附一題嵌入題。
  - 嵌入題的格式和題庫題目完全相同，參考 `data\history\questions\tw-1a.json`。題型可用 single、order、chain、decode、clue、compare、match，不要 click 或圖表。
  - 欄位要有 id、type、stem、theme、skill、era、eventIds、kp、explain，以及各題型自己的欄位；level 等於 era。
  - id 用 `s-<章id>-<序號>`，例如 `s-F1-1`。
  - 嵌入題的 status 跟著章節走，不用另外填。
  - 題目要考這段故事剛發生的事，讓學生用歷史思考作答，不考年份。
- **detective**：6–10 句的一段文字，混進 2–3 句時代錯置的內容，例如鄭氏時期出現火車、日治初期出現新臺幣。每一處錯置都要在 explain 說明哪個時代才有、課本依據是什麼。
- **factFiction**：4–6 條，史實和虛構都要有。
- **unlock**：解鎖的館藏卡，用事件 id，就是這章的 eventIds。
- 正解選項不能老是最長的那個；選項長度要平均。

## 檔案
- 寫進指定的 `data\history\stories\<檔名>.json`，格式為 `{ "line": "tw", "title": "林家的五代人", "chapters": [...] }`。
- 只覆寫自己負責的那個檔，manifest 已經登錄好。
- 嵌入題的 id 不可和題庫或其他章重複；題幹也不要和題庫題目一字不差。
- 寫完執行 `node -e "JSON.parse(require('fs').readFileSync('<檔案>','utf8'))"`，確認是合法的 JSON。
